# Undangan Ade & Ros — GitHub Pages

## Isi
- `index.html` — undangan utama.
- `buat-link.html` — generator link tamu, jadi nama penerima tidak perlu diubah di kode.
- `style.css` — tampilan dan animasi.
- `script.js` — perpindahan halaman.
- `assets/` — gambar undangan yang sudah dikompres ke WebP.

## Upload ke GitHub
1. Buat repository baru di GitHub.
2. Upload semua isi folder ini.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu Save.
6. Tunggu GitHub Pages aktif.
7. Buka `buat-link.html` dari alamat GitHub Pages tersebut.
8. Masukkan nama tamu → **Buat Link** → **Salin**.

Contoh hasil:
`https://USERNAME.github.io/NAMA-REPO/index.html?to=Bapak%20Budi`

## Urutan interaksi
1. Sampul depan.
2. Ketuk → animasi membalik ke belakang.
3. Ketuk → masuk ke bagian dalam.
4. Ketuk → masuk ke halaman isi.
5. Ketuk lagi → kembali ke sampul.

Tidak memakai framework, library, CDN, atau font online sehingga ringan dan tetap bisa jalan walaupun koneksi tidak stabil setelah halaman selesai dimuat.
